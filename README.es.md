## Acerca de este repositorio

Este es el origen canónico y versionado de la serie numerada de documentos de trabajo de
Woodfine Capital Projects Inc. (`WCP-NNN`, asignados de forma secuencial y permanente — nunca
reutilizados, nunca ligados a un año calendario). La página `/working-papers` de cada sitio
renderiza sus documentos asignados a partir de esta misma fuente — este repositorio, no
ningún sitio individual, es el registro del sistema.

**Autoría institucional, no individual.** Cada documento es preparado y publicado por
Woodfine Management Corp. en nombre de Woodfine Capital Projects Inc. Ningún documento lleva
autor, firma o colaborador nombrado — la sección `## Contributors` de cada documento dice
únicamente "Prepared by Woodfine Management Corp." y nada más.

**Documento de trabajo, de forma permanente.** Cada documento aquí es preliminar y está
sujeto a revisión por diseño — esto no es un área de preparación previa a la publicación para
una futura revista arbitrada. Un documento permanece como documento de trabajo, lleva un
número de versión (no un objetivo de presentación), y se revisa en el lugar en vez de
retractarse y reemplazarse cuando nueva evidencia cambia el panorama.

**Cero enlaces externos, por regla editorial.** Ningún documento de esta serie enlaza a
ningún sitio, producto o tercero externo — incluyendo entre sí — en ninguna parte de su
cuerpo. Las referencias cruzadas entre documentos se registran en metadatos legibles por
máquina (`draws_from:`) para herramientas, nunca se muestran como un enlace clicable en el
cuerpo del texto. La sección `## References` al final de cada documento es la única
excepción: una entrada bibliográfica con una URL o DOI real puede aparecer como enlace ahí,
una vez concluido el argumento. Sin comparaciones con competidores nombrados — los productos
comerciales se describen de forma genérica, por categoría, nunca por nombre.

**CC BY 4.0.** Cada documento puede compartirse y adaptarse para cualquier propósito, incluso
comercial, con atribución. Véase [LICENSE](LICENSE).

## Cómo se usa este repositorio

Cada documento es un archivo Markdown simple con un bloque estructurado de metadatos YAML
(`schema: journal-v2`) — título, tesis, resumen, citas y metadatos de versión — seguido de un
aviso de divulgación en el encabezado, una apertura guiada por la tesis, de dos a cuatro
secciones numeradas argumentadas en los términos propios del documento, y una secuencia fija
de cierre: `## References`, `## Contributors`, `## How this paper was produced`,
`## Disclosures`, y `## Data and reproducibility`.

Este repositorio es la fuente; no es en sí mismo un sitio web renderizado. La forma
renderizada real de cada documento vive en la página `/working-papers/<slug>` de su sitio
asignado.

## Divulgaciones

Nada en este repositorio constituye una oferta de venta, ni una solicitud de oferta de
compra, de ningún valor o interés en bienes raíces. Las declaraciones prospectivas en
cualquier documento reflejan las expectativas actuales a partir de la fecha de versión
indicada en ese documento y están sujetas a cambios sin previo aviso.
